# LuminaServerLauncher
LuminaServerLauncher is a Minecraft Server Manager.It starts the server using a VPN.It can download server, manage server properties, manage VPN and launch server.

## Features

- Launch Minecraft server
- Download Minecraft server
- Manage VPN
- Manage server properties
- Manage JVM properties

## Directory Layout

```
LuminaServerLauncher.jar/
    assets/                    - App assets
    com/                       - Libs (com)
    io.github.codefarmerfox/   - Source code package
        lwjgl3/                - Lwjgl3 files
        luminaserverlauncher/  - Source code
    javazoom/                  - Libs (javazoom)

    macos/                     - Libs (macos)

    org/                       - Libs (org)

    .dylib                     - macOS linklibs

    config.json                - Config

```
